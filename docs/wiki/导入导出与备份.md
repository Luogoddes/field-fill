# 导入导出与备份

## 全量备份

在「IO」标签中点击「导出全部」，可以将所有 Profile、字段、预设导出为一个 JSON 文件。

## 导入备份

在「IO」标签中选择备份 JSON 文件并导入。导入会合并或覆盖现有数据，请谨慎操作。

## 单 Profile 导出

在「字段配置」标签中，点击 Profile 卡片的导出图标，可以导出单个 Profile。

## 单预设导出

在预设详情中点击 📋 复制 旁的导出按钮（如果存在），可以导出单个预设。

## 数据格式

备份 JSON 结构大致如下：

```json
{
  "_type": "uff-backup",
  "version": "1.4.8",
  "profiles": [...],
  "exportedAt": 1234567890
}
```

> 提示：定期导出备份可以防止数据丢失。
