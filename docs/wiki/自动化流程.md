# 自动化流程

自动化流程允许你按顺序执行多个步骤，例如：点击按钮 → 等待元素 → 填充表单 → 等待 → 再次点击。

## 创建流程

1. 切换到「自动化」标签。
2. 点击右上角 ＋ 创建新流程。
3. 输入流程名称。

## 添加步骤

点击「添加步骤」选择类型：

- **fill**：使用某个 Profile 的某个预设进行填充。
- **click**：点击指定选择器的元素。
- **wait**：等待指定毫秒。
- **waitFor**：等待指定选择器的元素出现。

## 排序

每个步骤左侧有 `⋮⋮` 手柄，可以拖动调整执行顺序。

## 运行

点击 ▶️ 运行，或设置流程为默认后通过右侧悬浮球触发。

## 右侧悬浮球

页面右侧会出现一个可拖拽的悬浮球，点击可以展开预设 / 流程面板，快速执行。
