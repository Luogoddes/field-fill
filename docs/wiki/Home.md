## ✨ 主要功能

| 功能 | 说明 |
| --- | --- |
| 🧩 多 Profile 管理 | 按项目 / 站点隔离字段与预设 |
| 📦 预设填充 | 一键将预设数据填充到当前页面表单 |
| 🎯 实时元素拾取 | 鼠标悬停 + 空格确认，自动生成 CSS / XPath 选择器 |
| 🤖 自动化流程 | 配置点击、填充、等待、等待元素等步骤序列 |
| 📝 智能解析 | 从文本中自动识别字段名与值，快速生成预设 |
| 🌙 暗黑模式 | 支持浅色 / 深色 / 跟随系统 |
| ⚡ 快捷键 & 右键菜单 | `Ctrl + Shift + F` 快速填充 |
| 🧲 右侧悬浮球 | 页面内快捷填充入口 |

## 🚀 一分钟上手

1. 安装扩展并打开 Popup。
2. 切换到「字段配置」，点击 🎯 拾取，悬停目标字段并按 `Space` 确认。
3. 切换到「预设填充」，点击右上角 ＋，选择要填充的字段并填写值。
4. 打开目标页面，点击预设卡片的 ✨ 填充，或按 `Ctrl + Shift + F` 使用全局默认预设。

更多细节请查看左侧目录。
