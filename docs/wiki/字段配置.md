# 字段配置

字段是表单元素在扩展中的映射。一个字段包含：

- **名称**：用于显示和文本解析。
- **选择器**：定位页面元素的 CSS 选择器或 XPath（前缀 `xpath:`）。
- **类型**：text / select / textarea / date / time，影响填充行为。
- **全宽**：标记为全宽后，预设详情中会以更大的输入框展示。

## 元素拾取

最快捷的字段创建方式。

1. 点击 🎯 拾取。
2. 在页面中移动鼠标，高亮目标元素。
3. 按 `Space` 确认，按 `Esc` 取消。
4. 回到 Popup 完善字段名称和类型。

## 手动添加

1. 点击「添加字段」。
2. 手动输入选择器，支持 CSS 选择器或 `xpath:...`。
3. 填写其他信息后保存。

## 批量扫描

点击「批量扫描」可以自动识别页面中可能的表单元素，供你批量选择添加。

## XPath 支持

当 CSS 选择器无法定位到复杂组件（如 Ant Design Select、Element UI 下拉框）时，可以使用 XPath：

```
xpath://input[@placeholder='请选择']
```

扩展会自动识别 `xpath:` 前缀并使用 `document.evaluate` 定位元素。
