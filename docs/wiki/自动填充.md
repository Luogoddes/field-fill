# 自动填充

自动填充可以在打开匹配 URL 的页面时，自动执行预设填充，无需手动点击。

## 开启自动填充

1. 在预设详情中切换到「填充配置」标签。
2. 勾选「启用自动填充」。
3. 添加 URL 匹配规则。

## URL 匹配规则

每条规则包含：

- **模式**：
  - `contains`：URL 包含指定字符串。
  - `exact`：URL 完全匹配。
  - `prefix`：URL 以指定字符串开头。
  - `suffix`：URL 以指定字符串结尾。
  - `regex`：使用正则表达式匹配。
- **URL / 表达式**
- **延迟**：页面加载后多少毫秒执行填充。
- **激活**：是否启用该规则。

## 全局延迟与覆盖

- **全局延迟**：没有单独设置延迟的规则会使用此值。
- **覆盖已有值**：如果字段已有内容，是否重新填充。

## 跳转填充

开启后，在自动填充完成后会跳转到指定 URL。适用于提交后需要继续填充下一个页面的场景。

## 注意事项

- 自动填充依赖 content script 在目标页面注入。
- 对于 SPA（单页应用），当前版本可能需要在页面完全加载后才会触发。
