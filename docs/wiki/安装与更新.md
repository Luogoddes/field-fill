# 安装与更新

## 系统要求

- Chrome / Edge 等基于 Chromium 的浏览器
- 支持 Manifest V3

## 安装方式

### 方法一：Edge 扩展商店（推荐）

访问 [Edge Add-ons 页面](https://microsoftedge.microsoft.com/addons/detail/%E5%AD%97%E6%AE%B5%E5%A1%AB%E5%85%85/aekjpmdkkenfoclhkmmjjchnebfaopej?hl=zh-CN) 安装。

### 方法二：手动安装（开发者模式）

1. 下载本仓库 `ZIP` 并解压，或 `git clone` 到本地。
2. 打开 Chrome / Edge，访问 `chrome://extensions/`。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择项目根目录即可。

## 更新

- 商店版本：浏览器会自动更新。
- 手动版本：重新下载仓库并覆盖旧文件，然后在 `chrome://extensions/` 页面点击刷新按钮。
