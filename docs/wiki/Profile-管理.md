# Profile 管理

Profile 是字段和预设的容器。你可以按项目、站点或业务场景创建不同的 Profile。

## 创建 Profile

1. 切换到「字段配置」标签。
2. 在顶部 Profile 卡片列表中点击 ＋。
3. 输入 Profile 名称和标签（可选）。
4. 点击保存。

## 切换 Profile

点击 Profile 卡片即可激活。当前激活的 Profile 会高亮显示。

> 注意：全局默认预设可以来自任意 Profile，快捷键和右键菜单都会使用它。

## 编辑与删除

- 点击 Profile 卡片的编辑图标可以修改名称和标签。
- 点击删除图标可以删除整个 Profile（会同时删除其下所有字段和预设，请谨慎操作）。

## 共享字段

每个 Profile 可以设置一组「共享字段」。在预设中开启「使用共享」后，该字段会统一使用共享字段中的值，方便批量修改。
