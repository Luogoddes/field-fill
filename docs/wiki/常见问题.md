# 常见问题

## Q1：填充时提示「未匹配到字段」

- 检查字段选择器是否正确。
- 如果页面是 SPA，元素可能是动态生成的，可以尝试增加自动填充延迟。
- 对于自定义组件下拉框，尝试使用 XPath 选择器（前缀 `xpath:`）。

## Q2：下拉框无法填充

- 确认字段类型是否为 `select`。
- 对于自定义 UI 组件（如 Ant Design、Element UI），普通 `select` 可能无效，需要使用 XPath 定位到真实输入或选项。
- 确保选项值与页面中的实际值一致（区分大小写和空格）。

## Q3：快捷键 `Ctrl + Shift + F` 无效

- 确认已设置全局默认预设。
- 检查浏览器快捷键设置是否被其他扩展占用。
- 确认当前页面允许扩展注入 content script（部分限制页面如 Chrome 商店无效）。

## Q4：自动填充没有触发

- 确认预设详情中开启了「自动填充」。
- 确认 URL 匹配规则正确且处于激活状态。
- 检查浏览器控制台是否有错误信息。
- 页面加载过慢时，适当增加延迟。

## Q5：Wiki 如何贡献

本 Wiki 源码位于仓库的 `docs/wiki/` 目录。如果你想补充内容，可以修改后提交 PR。
