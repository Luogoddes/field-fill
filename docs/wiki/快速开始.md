# 快速开始

本教程带你完成第一次表单填充。

## 1. 打开扩展

点击浏览器工具栏上的扩展图标，打开 Popup 弹窗。

## 2. 配置字段

1. 切换到「字段配置」标签。
2. 点击右上角的 🎯 拾取按钮。
3. 在目标页面上移动鼠标，目标字段会被高亮显示。
4. 按 `Space`（空格键）确认拾取，选择器会自动填入。
5. 填写字段名称，选择字段类型（text / select / textarea / date / time）。
6. 点击保存。

> 提示：如果拾取的是自定义组件下拉框，生成的选择器可能无法直接填充，此时可以尝试在「字段配置」中手动输入 XPath（前缀 `xpath:`）。

## 3. 创建预设

1. 切换到「预设填充」标签。
2. 点击右上角 ＋ 按钮。
3. 输入预设名称。
4. 在弹出的字段选择器中点击需要的字段（行点击即可选中）。
5. 点击确认。
6. 在预设详情中填写各字段的值，点击 💾 保存。

## 4. 执行填充

### 方式一：单次填充

在「预设填充」标签中，点击预设卡片的 ✨ 填充 按钮。

### 方式二：全局默认预设

1. 在预设详情中点击 ⭐ 默认，将其设为全局默认。
2. 在任意页面按 `Ctrl + Shift + F`，即可使用默认预设填充。
3. 或在页面空白处右键，选择「字段填充」。

## 5. 查看结果

页面会显示 Toast 提示，告诉你成功填充了几个字段。
