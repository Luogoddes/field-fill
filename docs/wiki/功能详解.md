# 功能详解

## 右键菜单与快捷键

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Shift + F` | 使用全局默认预设填充当前页面 |
| `Space` | 拾取模式下确认选中元素 |
| `Esc` | 取消拾取 |

### 右键菜单

在页面任意位置右键，选择「字段填充」，即可使用全局默认预设填充当前页面。

可以在「IO」标签中开启或关闭右键菜单。

## 共享字段

共享字段用于在多个预设中复用同一值。例如，一个项目中的「版本号」需要在多个预设中使用，可以将其设置为共享字段。

在预设详情中勾选字段的「使用共享」，该字段会读取 Profile 中共享字段的值，而不需要逐个预设填写。

## 文本视图

预设详情提供「文本」标签，可以按 `字段名：值` 的格式批量编辑。

适合从聊天记录、邮件、文档中复制字段信息后直接粘贴生成预设。

## 暗黑模式

点击 Popup 右上角的 🌙 / ☀️ 按钮切换主题，支持：

- 浅色
- 深色
- 跟随系统

## 右侧悬浮球

扩展会在页面右侧显示一个可拖拽的悬浮球，点击可展开：

- 全局默认预设
- 默认自动化流程
- 常用操作

悬浮球支持拖拽调整位置，避免遮挡页面内容。
